# Colección con iterador

Varios objetos `Vehiculo` (`Auto` y `Motocicleta`) agrupados en un `vector<Vehiculo*>` y recorridos con un iterador del lenguaje (`vector<Vehiculo*>::iterator`) para imprimir la información de todos.

## Compilar y ejecutar

```bash
g++ coleccion.cpp -o coleccion
./coleccion
```

## Salida

```
Auto: Toyota Corolla - 180 km/h - 4 puertas
Motocicleta: Yamaha R6 - 260 km/h - 600 cc
Auto: Ford Mustang - 250 km/h - 2 puertas
Motocicleta: Honda CBR500R - 190 km/h - 500 cc
Auto: Nissan Versa - 170 km/h - 4 puertas
```
